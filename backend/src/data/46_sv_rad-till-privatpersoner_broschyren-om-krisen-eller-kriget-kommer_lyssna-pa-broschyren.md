# Lyssna på broschyren Om krisen eller kriget kommer

Här finns broschyren inläst på svenska. Broschyren finns också i bibliotekskatalogen Legimus.

## Lyss­na på olika sätt

Att broschyren finns i bibliotekskatalogen Legimus betyder att du kan:

- läsa broschyren strömmande
- ladda ned broschyren och läsa den lokalt på valfri spelare
- kontakta ditt bibliotek och be dem om hjälp med att låna den.

### Skaffa konto till Legimus

Du behöver vara en registrerad användare för att använda bibliotekskatalogen Legimus tjänster. Ditt lokala bibliotek kan hjälpa till med att skaffa ett användarkonto. Det är Myndigheten för tillgängliga medier som ansvarar för Legimus.

[Legimus webbplats](http://www.legimus.se/)
