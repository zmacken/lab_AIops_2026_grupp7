# Brandsäkerhet vid kris och krig

Ett bra brandskydd är viktigt varje dag, men blir kanske ännu viktigare vid kris och krig. Om du har ett bra brandskydd hemma och vet hur du förebygger brand är du också bättre förberedd för att kunna hantera bränder i din bostad vid kris och krig.

- [Sceniarier att förbereda dig på inför kris och krig när brandriskerna förändras](https://www.mcf.se/sv/rad-till-privatpersoner/brandsakerhet/brandsakerhet-i-hemmet/brandsakerhet-vid-kris-och-krig/#Sceniarier_att_f_rbereda_dig_p__inf_r_kris_och_krig_n_r_brandriskerna_f_r_ndras)

Erfarenheter från bland annat Ukraina visar att brandriskerna förändras i ett samhälle som befinner sig i krig. Förutom de bränder som kan uppstå till följd av militära angrepp kan risken för bränder öka när människor behöver använda sig av alternativa lösningar för värme, el, vatten och matlagning.

## Var­för blir brand­skyd­det extra vik­tigt?

Vid kris och krig kan samhällets resurser som räddningstjänst, sjukvård och kommunikationer bli hårt belastade. Det kan göra att det tar längre tid än normalt att få hjälp.

Genom att förebygga bränder och kunna hantera mindre incidenter själv, ökar du säkerheten och tryggheten för dig, din familj och grannar. Du bidrar också till att avlasta trycket på samhällets resurser så att hjälpen kan gå till de som behöver den mest.

Tänk på att inte utsätta dig själv eller andra för fara om du måste släcka en brand.

## Sce­ni­a­ri­er att för­be­re­da dig på när brand­ris­ker­na för­änd­ras vid kris och krig

Vid allvarliga störningar i samhället kan du behöva använda alternativa lösningar för värme, el och matlagning. Det kan skapa nya brandrisker.

Här är några scenarion du behöver vara förberedd på.

- [Alternativ uppvärmning](https://www.mcf.se/sv/rad-till-privatpersoner/brandsakerhet/brandsakerhet-i-hemmet/brandsakerhet-vid-kris-och-krig/#)


Försvinner elen kan kaminer, gasolvärmare eller andra reservlösningar behöva användas för att hålla din bostad varm. För att minska risken för brand eller kolmonoxidförgiftning:



  - Använd utrustning enligt tillverkarnas instruktioner.
  - Se till att ventilationen är god, för att minska risken för kolmonoxidförgiftning. Installera gärna en kolmonoxidvarnare.
  - Se till att saker som lätt kan börja brinna inte finns nära värmekällan.
  - Lämna aldrig utrustningen utan uppsikt.

- [Alternativa strömkällor](https://www.mcf.se/sv/rad-till-privatpersoner/brandsakerhet/brandsakerhet-i-hemmet/brandsakerhet-vid-kris-och-krig/#)


Generatorer, batterier, powerbanks och andra reservkraftslösningar kan vara viktiga vid strömavbrott. För att minska brandrisken:



  - Använd CE-märkta produkter på det sätt de är avsedda för.
  - Använd inte skadad utrustning.
  - Följ tillverkarens anvisningar.
  - Ladda batterier under uppsikt.

[Ladda och hantera dina batterier säkert](https://www.mcf.se/sv/rad-till-privatpersoner/brandsakerhet/brandsakerhet-i-hemmet/ladda-och-hantera-dina-batterier-sakert/)

- [Alternativ matlagning](https://www.mcf.se/sv/rad-till-privatpersoner/brandsakerhet/brandsakerhet-i-hemmet/brandsakerhet-vid-kris-och-krig/#)


Campingkök, stormkök och andra alternativa lösningar för att tillaga mat kan innebära ökad brandrisk om de används fel. Tänk igenom hur du kan laga mat på ett säkert sätt och var särskilt försiktig om utrustningen används inomhus.



[Läs mer om spritkök och tändvätska](https://www.mcf.se/sv/rad-till-privatpersoner/brandsakerhet/brandsakerhet-i-skog-mark-och-tradgard/spritkok-och-tandvatska/)



[Läs mer om hemberedskap](https://www.mcf.se/sv/rad-till-privatpersoner/hemberedskap---preppa-for-en-vecka/)


- [Levande ljus](https://www.mcf.se/sv/rad-till-privatpersoner/brandsakerhet/brandsakerhet-i-hemmet/brandsakerhet-vid-kris-och-krig/#)


Levande ljus kan ge ljus vid strömavbrott och även lite värme. Men levande ljus är också en vanlig orsak till bostadsbränder.



Tänk på att:



  - Aldrig lämna levande ljus utan uppsikt.
  - Placera ljus på ett underlag som inte kan fatta eld.
  - Håll avstånd till gardiner och annat brännbart material.

[Läs mer om brandskydd i hemmet](https://www.mcf.se/sv/rad-till-privatpersoner/brandsakerhet/brandsakerhet-i-hemmet/)

- [Tekniskt brandskydd som slutar fungera](https://www.mcf.se/sv/rad-till-privatpersoner/brandsakerhet/brandsakerhet-i-hemmet/brandsakerhet-vid-kris-och-krig/#)


Vid el- eller vattenbortfall kan vissa brandskyddsfunktioner som är beroende av el eller vatten påverkas, så som automatiskt aktivering av brandgasventilering eller sprinkler. Det är därför viktigt att känna till om det finns brandskydd som är beroende av detta och hur brandskyddet påverkas om dessa slutar fungera. Ibland kan andra åtgärder behövas om dessa brandskydd skulle påverkas.


## Vad kan du göra redan idag?

Har du ett bra brandskydd i din bostad i ett normalläge står du också bättre rustad vid kris och krig. Den största skillnaden vid kris eller krig är att den egna beredskapen blir viktigare då samhället i övrigt är ansträngt.

## För bra be­red­skap om det bör­jar brin­na bör du ha:

- minst 1 fungerande brandvarnare på varje våningsplan
- minst en brandsläckare
- en brandfilt på en lättillgänglig plats
- kunskap om hur utrustningen används

## Se till att du vet:

- hur brandskyddet ska kontrolleras och skötas
- hur du ska agera vid utrymning
- hur en brandsläckare fungerar
- de vanligaste brandriskerna i hemmet
- hur ovanstående fungerar genom att öva tillsammans. Det kan du göra genom att till exempel läsa på instruktionen till brandsläckaren och utrymningsöva hemma.
