# Way of Working

## 1. Hybridarbete

Vi jobbar hybrid. Fördelningen mellan skolan och distans bestäms på överenskommelse inom teamet.

## 2. Check-in

Check-in sker kl. 10.00, om inget annat sägs.

## 3. Punktlighet

Vi kommer i tid till möten, check-ins och överenskommelser. Kan du inte komma i tid, meddela teamet i förväg.

## 4. Dagar på plats

Vi är på plats på onsdagar och torsdagar.

## 5. Öppen kommunikation

Vi pratar öppet med varandra. Frågor, problem och blockers lyfts tidigt, och alla ska känna att det är tryggt att säga vad man tycker.

## 6. Github
Alla jobbar i sin egen branch.
Egen branch pushas först till development.
Därefter går development vidare till main.
egen branch  →  development  →  main

Git commit message enligt best practice.
